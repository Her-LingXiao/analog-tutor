# 模电检查清单

用法：给出数值结果前，按本题实际发生的环节生成一张短清单。

- 只保留会命中的项；不适用项直接删掉，不要写“不适用”凑数。
- 题型专属项看“何时查”，条件不成立就不列。比如单端输出不查 R_L/2，没有旁路电容不查 C_e。
- 同一检查点只出现一次：通用项与题型项重叠时，保留更具体的那条。
- 一条都不命中时，写一行“本题无适用检查项”，不要硬凑。
- 先读 `references/user-errors.md`，同题型命中的“以后必查”项优先并入。
- 每项答“是 / 否”并附一句依据；答“否”先修正再继续。
- 清单要出现在最终输出里，但只留相关项。

## 一、通用项（按条件取用）

1. 单位是否统一，换算是否写清？（凡出现 mV/V、μA/mA、Ω/kΩ 混用）
2. 增益或比例的符号是否显式写出？（凡求 A、A_f、CMRR 等有方向的量）
3. 受控源方向、电流参考方向是否与所设一致？（凡含受控源或设了电流方向）
4. 近似条件是否写明并验证？（凡用了小信号、理想运放、深度负反馈、忽略 r_bb' 等）
5. 题目问的量是否答全，形式是否匹配？（凡问倍数/dB、单端/双端、有效值/峰值/峰峰值）
6. 分析前假设的工作区域是否先确认过？（凡出现“放大区 / 线性区 / 截止 / 饱和”假设）
7. 题目信息量是否够套这条 SOP？不够时是否降级（端口方程、方框图、拆单级）而不是硬凑内部参数？（凡只给端口数据、方框图或多级结构）

## 二、分题型项

### 共射放大

1. 偏置类型是否先判对（固定 / 分压 / 集电极-基极反馈）？（凡给偏置网络）
2. 分压式是否验算 I_1 ≫ I_BQ 后才用 U_BQ 分压公式？（凡分压式偏置）
3. C_e 是否直流通路开路、交流通路短路？（凡有旁路电容）
4. r_be 里的 I_EQ 是否用 mA 代入？（凡求 r_be）
5. A_u 是否写了负号，R_L' 是否按交流通路并联？（凡求 A_u）
6. R_i 是否包含 R_b1∥R_b2？（凡求 R_i）

### 共集 / 共基

1. 组态是否按交流通路的输入极、输出极判，而不是看画图位置？（必查）
2. 共集 A_u 是否同相且不大于 1？（凡共集）
3. 共集 R_o 是否含 (r_be+R_b∥R_s)/(1+β) 的并联？（凡求共集 R_o）
4. 共基 R_i 是否除以 (1+β)？（凡共基）
5. 共基 A_u 是否同相？（凡共基）

### 负反馈判断

1. 取样是否用“输出短路法”单独判？（必查）
2. 比较是否按输入端串联 / 并联单独判？（必查）
3. 极性是否走完瞬时极性法三步？（必查）
4. 深度负反馈 |1+AF| ≫ 1 是否验证后才写 A_f ≈ 1/F？（凡用近似）
5. 闭环增益的量纲是否与组态匹配（电压比 / 互阻 / 互导）？（凡求 A_f）

### 差分放大

1. 长尾或镜像电流源的 I_0 是否除以 2 得到每管电流？（凡长尾 / 恒流源）
2. 双端输出带载是否用 R_L/2？（仅双端输出且带载）
3. 单端输出增益是否带 1/2？（仅单端输出）
4. CMRR 问的是倍数还是 dB，是否按问法给？（凡求 CMRR）
5. 共模分析时每管的发射极电阻是否用 2R_e？（凡算 A_uc）

### 运算电路

1. 是否先判线性区 / 非线性区（有无负反馈）？（必查）
2. 虚短虚断是否只在线性区使用？（凡用虚短虚断）
3. 输出是否与 ±U_om 比较、检查是否触轨？（凡可能饱和）
4. 反相端与同相端是否接对，增益符号是否对？（凡比例电路）

### 功率放大

1. OCL 与 OTL 的 U_om 是否各自用对（V_CC 与 V_CC/2）？（必查）
2. 效率是否说明忽略了 U_CES？（凡给效率数值）
3. 单管管耗是否按总功耗的一半算？（凡算管耗）
4. 选管耐压是否按 2V_CC 校核？（凡选管）

### 波形产生

1. 幅度条件与相位条件是否分别验证？（必查）
2. 起振条件 |AF| > 1 与平衡条件 |AF| = 1 是否分开写？（必查）
3. 文氏桥 F = 1/3、起振要求 A > 3 是否写出？（仅文氏桥）
4. 稳幅环节随幅度变化的方向是否说明？（凡有稳幅）

### 稳压电源

1. U_2 是否按有效值代入？（凡用 U_2）
2. 纹波频率是否与整流方式匹配（半波 50 Hz、全波 100 Hz）？（凡算纹波）
3. 78xx / 79xx 输入输出压差是否满足最小压差？（凡用三端稳压器）
4. 整流二极管 U_RM 是否按 √2·U_2 校核？（凡校核二极管）

## 三、错题本联动

用户算错时，把错误追加到 `references/user-errors.md`。下次同题型生成清单前先读该文件，把命中的“以后必查”项并入，并标注来自错题本。不同题型通用的教训（单位、符号、近似条件）可跨题型并入。
