# 个人错题本

记录用户实际犯过的错，供同题型检查清单调用。只记真实发生过的，不预填、不编造。

写法：往下表末尾追加，一行一条。

| 日期 | 题型 | 错误现象 | 归因标签 | 以后必查 |
|---|---|---|---|---|

规则：

- 归因标签只用 concept / sop / formula / circuit / state / calculation。
- 同一现象不重复追加；再次出现时在“以后必查”后标 ×2、×3。
- 生成检查清单时，优先并入同题型命中的行；单位、符号、近似条件这类通用教训可跨题型并入。
- 用户答对但过程里出现过的错，也按一条记，别等它下次再犯。
