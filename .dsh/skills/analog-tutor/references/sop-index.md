# 模电题型 SOP 索引

八类题型各含重点、思维通路、固定步骤与易错点。符号按康华光教材：U_BEQ、I_BQ、I_CQ、U_CEQ、r_be、A_u、R_i、R_o、R_L、R_s、β。每类末尾的检查行指向 `references/checklist.md` 对应小节。

> **ElectroLab Mode 规则**
> 会话处于 ElectroLab Mode 时，所有数值结果必须来自 ElectroLab 的 solver 调用，不得用手算结果冒充。调用前先 `solver_info` 确认签名，把类型化值写入 slot，再 `call`。ElectroLab 的 38 个内置求解器覆盖电路、电子学、传递函数、滤波器等，模电题优先选电路与电子学类。ElectroLab 不可用时，退回手算 + SymPy 复核，并在答案里标注“未仿真验证”。

## 1. 共射放大

**重点**：Q 点定 r_be，r_be 定 A_u；分压偏置的适用条件、C_e 在直流通路与交流通路中的相反身份、A_u 的负号，是三个主要得分点。

**思维通路**：看偏置类型 → 画直流通路求 Q 点 → 判放大区 → 画交流通路 → 算 r_be → 算 A_u / R_i / R_o → 校核符号与量级。

**常见问法**：求 Q 点与 A_u、R_i、R_o；给输出波形判断失真类型；换 β 或换负载后 Q 点怎么变。

### 步骤

1. 识别偏置：固定偏置、分压式偏置、集电极-基极偏置。标出 V_CC、R_b1、R_b2、R_c、R_e、R_L、C1、C2、C_e。
2. 画直流通路：电容开路，输入输出端开路。分压式先验算 I_1 ≈ (5~10)I_BQ，满足才可用 U_BQ ≈ R_b2/(R_b1+R_b2)·V_CC。
3. 求 Q 点：
   - U_BQ = R_b2/(R_b1+R_b2)·V_CC
   - U_EQ = U_BQ − U_BEQ（硅管取 0.7 V，题目另给按题目）
   - I_EQ = U_EQ/R_e
   - I_CQ ≈ I_EQ，I_BQ = I_EQ/(1+β)
   - U_CEQ = V_CC − I_CQ·R_c − I_EQ·R_e
4. 判工作区：U_CEQ > U_BEQ（集电结反偏）且 U_CEQ > U_CES（约 0.3 V）。不满足就进饱和或截止，停止小信号计算。
5. 画交流通路：耦合电容、旁路电容短路，直流电源置地。
6. 求 r_be：r_be = r_bb' + (1+β)·26 mV/I_EQ，I_EQ 用 mA，26/I_EQ 得 Ω。题目未给 r_bb' 时取 200 Ω 并声明。
7. 求 A_u：R_L' = R_c∥R_L；A_u = −β·R_L'/r_be。R_e 未旁路时 A_u = −β·R_L'/[r_be+(1+β)R_e]。负号必须写出。
8. 求 R_i、R_o：R_i = R_b∥r_be，其中 R_b = R_b1∥R_b2；R_o ≈ R_c（康华光忽略 r_ce）。
9. 需要时求源电压增益：A_us = A_u·R_i/(R_i+R_s)。

### 本题型易错点

- 直流通路里把 C_e 当短路，Q 点全错。
- 分压式不验算 I_1 ≫ I_BQ，直接套 U_BQ 公式。
- r_be 里的 I_EQ 用 μA 代入。
- A_u 丢负号，或把 R_L 当开路。
- R_i 漏掉偏置电阻 R_b1∥R_b2。
- 求 U_CEQ 时 I_CQ 与 I_EQ 混用。

详细检查项见 references/checklist.md 对应小节。

## 2. 共集 / 共基

**重点**：先按交流通路判组态（输入极、输出极），再选公式组；共集考跟随与阻抗变换（A_u≈1 同相、R_i 大、R_o 小），共基考低输入电阻、同相、宽带（R_i 小、R_o 大）。

**思维通路**：画交流通路 → 找输入极与输出极定组态 → 选对应公式组 → 算 A_u / R_i / R_o → 用“共集 A_u≤1、共基 R_i 很小”校核直觉。

**常见问法**：先判组态再求 A_u、R_i、R_o；问共集为什么适合作缓冲级；两级组态组合后的输入、输出电阻。

### 步骤

1. 判组态：输入基极、输出发射极是共集；输入发射极、输出集电极是共基；输入基极、输出集电极是共射。看交流通路，不看画图位置。
2. 共集（射极跟随器）：
   - Q 点算法与共射相同。
   - R_L' = R_e∥R_L。
   - A_u = (1+β)R_L'/[r_be+(1+β)R_L']，同相，略小于 1。
   - R_i = R_b∥[r_be+(1+β)R_L']，R_b = R_b1∥R_b2。
   - R_o = R_e∥[(r_be+R_b∥R_s)/(1+β)]。
   - 用途：缓冲、阻抗变换、输出级。
3. 共基：
   - Q 点同上，注意基极交流接地。
   - R_L' = R_c∥R_L。
   - A_u = β·R_L'/r_be，同相，数值与共射相当。
   - R_i = R_e∥[r_be/(1+β)] ≈ R_e∥(26 mV/I_EQ)，很小。
   - R_o ≈ R_c，很大。
   - 用途：高频、宽带、电流跟随。
4. 检查近似：共集写 A_u ≈ 1 的条件是 (1+β)R_L' ≫ r_be；不满足就不能写 1。

### 本题型易错点

- 共集 A_u 写成负号。
- 共集 R_o 直接写 R_e，漏掉 (r_be+R_b∥R_s)/(1+β) 的并联。
- 共基 R_i 写成 R_e∥r_be，漏掉除以 (1+β)。
- 把共集当电压放大级，期待 A_u 大于 1。
- 共基 A_u 的同相/反相判错。
- 交直流通路混淆，没看出 R_e 在共基里是输入电阻的一部分。

详细检查项见 references/checklist.md 对应小节。

## 3. 负反馈判断

**重点**：取样、比较、极性是三件独立的事，必须分开判；组态名由三者组合；深度负反馈近似先验 |1+AF| ≫ 1。

**思维通路**：找反馈支路 → 输出短路判取样 → 输入端看串并联判比较 → 瞬时极性法判正负 → 组合命名 → 验深度条件 → 算 A_f 与 R_i、R_o 的变化。

**常见问法**：判断反馈组态；求 A_f；说明对 R_i、R_o 的影响；给方框图从 A、F 求闭环增益。

### 步骤

1. 找反馈元件：连接输出回路与输入回路的电阻、电容或变压器。
2. 判取样：输出端短路（u_o = 0）后反馈信号消失，是电压取样；短路后反馈仍在，是电流取样。
3. 判比较：反馈信号与输入信号在输入端串联、电压相减，是串联比较；接在同一节点、电流相减，是并联比较。
4. 瞬时极性法判极性：
   - 设输入 u_i 为 +；
   - 沿放大通路逐级标极性（共射反相，共集同相，共基同相，运放反相端反相）；
   - 回到输入端，看反馈信号削弱还是增强净输入；
   - 削弱是负反馈，增强是正反馈。
5. 组态命名：电压串联、电压并联、电流串联、电流并联。
6. 验证深度负反馈条件：|1+AF| ≫ 1 时才可写 A_f ≈ 1/F。
7. 求闭环增益：按组态选式。电压串联常用 A_uf = 1+R_f/R_1；电压并联常用 A_uf = −R_f/R_1。其余组态从 A_f = A/(1+AF) 推。
8. 说明反馈对输入输出电阻的影响：串联提高 R_i，并联降低 R_i；电压取样降低 R_o，电流取样提高 R_o。

### 本题型易错点

- 取样、比较、极性混在一起判，直接写“电压串联”没有依据。
- 输出短路测试做错，把负载短路当成输出短路。
- 瞬时极性法跳步，只凭“看起来是负反馈”。
- 正反馈也套 A_f = A/(1+AF)。
- 没验证深度负反馈条件就写近似。
- 电流取样时反馈点选在负载另一端。

详细检查项见 references/checklist.md 对应小节。

## 4. 差分放大

**重点**：对称半电路思想；差模与共模分开算；单端输出比双端少一半；CMRR 问倍数还是 dB 要看题。

**思维通路**：判长尾或镜像 → 求 I_0 与每管 Q 点 → 差模半电路算 A_ud → 共模算 A_uc → 求 CMRR → 核对单端/双端与带载。

**常见问法**：求 A_ud、A_uc、CMRR；单端与双端对比；只给两次输入输出测量反推增益（走下面的端口测量模式）。

**端口测量模式（黑箱题）**：只给输入、输出电压而不给内部电路时，跳过 Q 点。取 u_id = u_i1 − u_i2，u_ic = (u_i1 + u_i2)/2，列 u_o = A_d·u_id + A_c·u_ic；两次测量列两式，相加得 A_c，相减得 A_d；CMRR 用 20lg|A_d/A_c| 换算成 dB。

### 步骤

1. 识别电路：长尾式、镜像电流源、恒流源负载；单端输出还是双端输出；有无调零电位器。
2. 求静态工作点：
   - 长尾：I_0 ≈ (V_EE − U_BEQ)/R_e（双电源，忽略基极电流），I_CQ1 = I_CQ2 = I_0/2。
   - 镜像：I_0 = I_R = (V_CC − U_BEQ)/R。
   - U_CQ = V_CC − I_CQ·R_c。
3. 差模分析：
   - 双端输出：A_ud = −β·R_c/r_be；带负载 R_L 时 R_L' = R_c∥(R_L/2)。
   - 单端输出：A_ud1 = −β·(R_c∥R_L)/(2r_be)。
   - 差模输入电阻 R_id = 2r_be（双端）。
4. 共模分析：
   - 双端输出、理想对称：A_uc ≈ 0。
   - 单端输出：A_uc1 = −β·(R_c∥R_L)/[r_be+(1+β)·2R_e] ≈ −R_c/(2R_e)。
5. 求 CMRR：CMRR = |A_ud/A_uc|；dB 形式为 20lg|A_ud/A_uc|。题目问倍数还是 dB，按问法给。
6. 写清单端与双端的区别：增益差 2 倍，CMRR 差很多，输出是否浮地。

### 本题型易错点

- 长尾 I_0 忘记除以 2。
- 双端输出带载时用 R_L，而不是 R_L/2。
- 单端输出增益漏掉 1/2。
- CMRR 把倍数当 dB。
- r_be 里的电流用错。
- 共模分析时把每管的 R_e 用成 R_e/2。

详细检查项见 references/checklist.md 对应小节。

## 5. 运算电路

**重点**：第一件事永远是判线性区（有无负反馈），不是列虚短虚断；线性区列节点方程，非线性区按比较器处理；结果要跟 ±U_om 对。

**思维通路**：看反馈接法 → 判线性/非线性 → 线性区用虚短虚断列节点方程，非线性区比较 u+ 与 u− 定输出和阈值 → 检查触轨与限幅。

**常见问法**：求 u_o 表达式；判线性还是非线性；画传输特性、求阈值；算触轨后的实际输出。

### 步骤

1. 先判运放是否在线性区：输出到反相端有负反馈通路，且没有正反馈主导，是线性区；无负反馈或正反馈主导，是非线性区（比较器、施密特触发器）。
2. 线性区：
   - 虚短 u+ = u−，虚断 i+ = i− = 0；
   - 对反相端、同相端列节点电流方程；
   - 反相比例 A_u = −R_f/R_1，同相比例 A_u = 1+R_f/R_1；
   - 加法、减法、积分、微分从节点方程推，不背错形式。
3. 非线性区：
   - 不写虚短；
   - 比较 u+ 与 u−，输出 ±U_om（接近电源轨，题目给 U_om 按题目）；
   - 有正反馈时求阈值 U_T，画传输特性。
4. 检查输出是否触轨：算出的 u_o 超过 ±U_om 时实际被限幅，线性区假设失效。
5. 题目给输入偏置电流、共模范围时再校核，未给不引入。

### 本题型易错点

- 默认虚短虚断，不判负反馈。
- 比较器题里写 u+ = u−。
- 反相端与同相端接反，增益符号错。
- 积分、微分的时间常数用错，R 与 C 位置颠倒。
- 输出已触轨仍按线性公式给结果。
- 忽略正反馈带来的迟滞。

详细检查项见 references/checklist.md 对应小节。

## 6. 功率放大

**重点**：OCL 与 OTL 的电源、U_om 对应关系；P_om、η、单管管耗三个公式；交越失真归因于乙类无静态偏置。

**思维通路**：认电路（OCL / OTL / 变压器耦合）→ 定 U_om → 算 P_om 与 η → 算单管管耗 → 判交越失真 → 选管校核。

**常见问法**：求 P_om、η、单管管耗；判断交越失真及消除办法；按耐压、电流、功耗选功率管。

### 步骤

1. 识别 OCL、OTL、变压器耦合；双电源还是单电源；负载 R_L。
2. 求最大输出：
   - OCL：U_om = V_CC − U_CES，P_om = U_om²/(2R_L) ≈ V_CC²/(2R_L)。
   - OTL：U_om = V_CC/2 − U_CES，P_om = U_om²/(2R_L) ≈ V_CC²/(8R_L)。
3. 求效率：η = P_o/P_V。OCL 最大 η = (π/4)·U_om/V_CC ≈ 78.5%（忽略 U_CES）；P_V = 2V_CC·U_om/(πR_L)。
4. 校核管耗：单管 P_T = (P_V − P_o)/2；最大管耗出现在 U_om = 2V_CC/π，P_Tmax ≈ 0.2P_om。
5. 判交越失真：乙类无静态偏置，u_i 过零附近两管都截止；改甲乙类，给少量静态偏置。
6. 选管：U_(BR)CEO > 2V_CC，I_CM > U_om/R_L，P_CM > P_Tmax。

### 本题型易错点

- OCL 与 OTL 的 U_om 混用（V_CC 与 V_CC/2）。
- 效率里直接代 V_CC 却不说明忽略了 U_CES。
- 管耗按总功耗算，没除以 2。
- 交越失真说成饱和失真。
- 选管耐压只按 V_CC 算，漏掉 2V_CC。
- 忽略 R_L 上的实际电压摆幅。

详细检查项见 references/checklist.md 对应小节。

## 7. 波形产生

**重点**：相位条件决定“能不能振”，幅度条件决定“振多大”；起振 |AF|>1、平衡 |AF|=1 要分开；稳幅环节的作用方向要写清。

**思维通路**：认电路（RC / LC / 晶体）→ 写 A 与 F → 验相位（正反馈）→ 验幅度（起振）→ 求 f_0 → 说明稳幅。

**常见问法**：判能否起振；求振荡频率；求起振条件与稳幅方式；给电路判断相位条件是否满足。

### 步骤

1. 识别电路：RC 桥式（文氏桥）、RC 移相、LC 三点式（电容三点式、电感三点式）、石英晶体。
2. 写振荡条件：AF = 1，即幅度 |AF| = 1，相位 φ_A + φ_F = 2nπ。
3. 写起振条件：|AF| > 1；靠非线性或稳幅环节把幅度拉回 |AF| = 1。
4. 求振荡频率：
   - 文氏桥 f_0 = 1/(2πRC)；
   - LC f_0 = 1/(2π√(LC))；
   - 石英 f_0 取晶体串联谐振频率。
5. 验相位：逐级算 A 与 F 的相移，确认总相移满足正反馈。
6. 说明稳幅：热敏电阻、二极管限幅、AGC，写清它随幅度增大是减弱还是增强反馈。

### 本题型易错点

- 只验幅度不验相位。
- 起振条件写成 |AF| = 1。
- 文氏桥谐振时 F = 1/3，起振要求 A > 3，漏掉。
- 三点式判据用错，分不清电容三点式与电感三点式。
- 把振荡频率当成谐振频率以外的频率。
- 稳幅环节的作用方向说反。

详细检查项见 references/checklist.md 对应小节。

## 8. 稳压电源

**重点**：链路分段（整流 → 滤波 → 稳压），每段一个公式；U_2 是有效值；纹波频率随整流方式变。

**思维通路**：拆链路 → 整流算 U_o(AV) → 滤波算 U_o 与纹波 → 稳压算输出与压差 → 校核器件耐压、电流、功耗。

**常见问法**：求 U_o 与纹波；选滤波电容；校核二极管耐压、电流与三端稳压器压差。

### 步骤

1. 分解链路：变压器 → 整流 → 滤波 → 稳压。
2. 整流：半波 U_o(AV) = 0.45U_2；桥式或全波 U_o(AV) = 0.9U_2。U_2 是副边有效值。
3. 滤波：电容滤波后 U_o ≈ 1.2U_2（全波、有载、工程估算）；纹波 U_r ≈ I_L/(2fC)（全波，f 为电网频率），半波 U_r ≈ I_L/(fC)。
4. 稳压：78xx/79xx 固定输出，压差至少 2~3 V；LM317 可调 U_o = 1.25(1+R_2/R_1)。
5. 负载效应：R_o = ΔU_o/ΔI_o；负载调整率用空载到满载的 ΔU_o/U_o 表示。
6. 器件校核：桥式整流二极管 U_RM = √2U_2，I_D = I_L/2；滤波电容耐压大于 √2U_2。
7. 估算稳压器功耗与散热：P = (U_i − U_o)·I_L。

### 本题型易错点

- U_2 用峰值而不是有效值。
- 桥式整流 I_D 写成 I_L。
- 纹波公式里 f 取 50 Hz 还是 100 Hz 不说明。
- 78xx 压差不够仍认为能稳压。
- LM317 公式漏掉 1.25 V 或写成 1.2 V。
- 滤波电容耐压按有效值选。

详细检查项见 references/checklist.md 对应小节。
